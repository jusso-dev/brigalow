How this server signs

  1. 01Digests only. Artifacts stay on the build machine.
  2. 02Verified identity. OIDC for people, workload tokens for CI jobs.
  3. 03Policy and approvals. One deny rejects; requesters and custodians cannot approve.
  4. 04Keys stay in the HSM. No export path, no software fallback.
  5. 05Hash-chained audit. Verify an export offline with brig audit verify.
